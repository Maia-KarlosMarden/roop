# ROOP — Relational Orbital Optimization Protocol

ROOP applies the Relational Invariance **G′r = Gp** — with G′ = 3ω²/4πρ and ρ = 3M/4πr³ (Maia, 2026, [Zenodo doi:10.5281/zenodo.20248439](https://doi.org/10.5281/zenodo.20248439), Section 2.2) — to two problems:

1. **Autonomous orbit control** — the relational thrust command ΔF (whether, how much and where to fire).
2. **Asteroid mass estimation** — the relational estimator M = ⟨h⟩²/(G·p_geom), closed in a loop with ΔF through ΔF_geom.

The reformulation is not new physics: it is an exact rereading of Kepler's laws, useful in the same sense as Lagrangian mechanics is useful relative to Newton.

This repository holds everything used to produce the technical article: the article itself, all simulation code, input data, raw results, logs and figure scripts.

## Running

Python 3 with NumPy, SciPy and Matplotlib (tested with NumPy 2.5, SciPy 1.18, Matplotlib 3.11). All seeds are fixed.

Run every script from inside `simulations/`, since they read and write files in the working directory:

```bash
cd simulations
python3 sim_market.py ...     # see each script's argument parsing for options
python3 econ.py
python3 en_fig9.py            # regenerates a figure from the stored results
```

Figure scripts write PNGs to `simulations/`; the copies used in the article are in `article/figures_*`.

Rebuilding the PDF (pandoc + headless Chrome):

```bash
cd article
pandoc ROOP_technical_article_EN.md -s --mathml --css style.css -o article.html
google-chrome --headless --no-pdf-header-footer --print-to-pdf=ROOP_technical_article_EN.pdf article.html
```
